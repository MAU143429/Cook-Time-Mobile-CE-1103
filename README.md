# 📱 Cook Time — Mobile App

## 🧠 Overview

This repository contains the mobile application for Cook Time, a social platform where chefs, aspiring cooks, and food enthusiasts can share and explore recipes. The app allows users to follow others, view cooking profiles, and engage with the culinary community.

---

## 📲 App Features

- User login, registration, and authentication
- Create, edit, and delete recipes
- Like and comment on other users' posts
- View feeds of the most recent or popular recipes
- Follow chefs and track their updates
- View personal or other users' profiles

---

## 🖧 Integration

The app communicates with the backend server using a REST API, sending and receiving JSON objects for:

- User and recipe management
- Feed updates
- Follower relationships

---

## 🧪 Technologies

- Mobile Framework: Xamarin Forms
- JSON over HTTP
- Real-time user feedback and responsive UI components
